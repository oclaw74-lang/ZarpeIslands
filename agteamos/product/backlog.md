# Backlog de producto — Zarpe Islands

**Generado**: 2026-08-18 (agteamos-new-project, Step 6 — modo incremental)

Este es el backlog de producto de ESTE proyecto (no confundir con el `BACKLOG.md` del propio plugin AgTeamOS). Vive completo aquí, en el repo, como fuente de verdad de qué falta hacer. **No se sube todo a GitHub de una vez** — para no gastar tokens/ruido creando 58 issues por adelantado, cada epic se sube a GitHub (milestone `MVP` + issue de epic + issues de tarea) recién cuando se va a empezar a trabajar en ella. El detalle completo de cada ticket (estilo user story, con AC numerados) vive en [`backlog-detail.md`](./backlog-detail.md).

## Cómo se usa

1. Se elige la siguiente epic a trabajar (orden sugerido: A → B → C → ... pero puede reordenarse).
2. Se crea el milestone `MVP` en GitHub si no existe, el issue de la epic (`[Epic] <nombre>`, tipo checklist) y los issues de sus tareas, copiando el contenido de `backlog-detail.md`.
3. Esta tabla se actualiza con el número de issue de GitHub y el estado.
4. Al cerrar la epic completa, se marca `done` acá.
